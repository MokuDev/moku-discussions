# moku-discussions

This repository hosts the **GitHub Discussions** that back the comment threads on
[**moku.cx**](https://moku.cx), rendered with [giscus](https://giscus.app).

There is no code here. Each discussion maps to a post on the blog.

- The blog source lives in [`MokuDev/blog`](https://github.com/MokuDev/blog).
- Comments are powered by the [giscus GitHub App](https://github.com/apps/giscus).
- Category: **Comments** (Announcement format).

Please keep discussion civil and on topic.
